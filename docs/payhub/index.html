ShopNest internal APIs / PayHub

PayHub Payments API v1.4.0

Internal payments service owned by payments-platform-team. Machine-readable spec: openapi.json

Base URL & auth

https://payhub.internal.shopnest.dev/api/v1
Header: X-PayHub-Key: <your key>

POST /payments

Create a payment for an order.

FieldTypeRequiredNotes
orderIdstringyes
amountnumberyesDecimal in major units, e.g. 499.99
currencystringnoINR (default) or USD
customerEmailstringno

Response 201: { paymentId, orderId, amount, currency, status, createdAt }
status: pending | authorized | captured | failed

GET /payments/{paymentId}

Fetch a payment. Response 200: Payment object.

POST /payments/{paymentId}/capture

Capture an authorized payment. Response 200: Payment with status: "captured".

POST /refunds

FieldTypeRequiredNotes
paymentIdstringyes
amountnumberyesDecimal in major units
reasonstringno

Response 201: { refundId, paymentId, status } — status: processing | completed | failed
